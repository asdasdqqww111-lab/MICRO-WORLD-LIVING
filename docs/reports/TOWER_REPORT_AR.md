# تقرير برج الصعود السماوي — Celestial Ascent Tower (100 طابق)

**الفرع:** `arena/complete-world-transformation` · **التاريخ:** 2026-11-13
**الحالة:** IMPLEMENTED (كود + اختبارات) — بانتظار تشغيل CI للتحقق النهائي

## 1. نظرة عامة

أكبر ميزة متبقية من خطة التحوّل — **برج زنزانة من 100 طابق قابل للعب مع 100 سيد طابق (Floor Master) فريد** — أصبحت الآن مطبقة فعليًا في المشروع، مبنية بالكامل فوق الأنظمة القائمة دون كسر أي عقد:

- التفريخ عبر `WorldRoot.spawn_creature()` القائم (يرفض تلقائيًا إعادة تفريخ السيد المهزوم ⇒ الثبات عبر الحفظ/التحميل مجاني).
- الانتقال عبر `teleport` القائم (`player.teleport(pos, zone)`).
- القتال عبر نظام `Creature` القائم (مراحل بوس متعددة، telegraph، Nova) — سادة الطوابق يستخدمون نفس مسار القتال الحقيقي.
- الرؤية عبر `_apply_zone_visibility` القائم (منطقة `tower` تخفي العالم الخارجي).
- الموسيقى عبر `AudioManager` القائم (منطقة البرج ⇒ موسيقى الزنزانة).

## 3. تصميم الأداء (أندرويد أولًا)

- **طابق واحد فقط في الذاكرة دائمًا** — التحميل يحرر الطابق السابق بالكامل (عقد + مخلوقات) قبل بناء الجديد.
- الطوابق تطفو فوق `(-500, 0, -200)` بتباعد 6م رأسيًا — لا تتقاطع مع المدينة أو الغابة أو السرداب.
- كل طابق: أرضية + 4 جدران + 4 أعمدة + حلقة + ضوء واحد بلا ظلال + 4-5 مخلوقات + سيد واحد ≈ نفس ميزانية السرداب الحالي.
- كل المواد `SHADOW_CASTING_OFF` والبناء خفيف العقد عمدًا.
- بوابة العالم الخارجي: spire بارتفاع 42م + تاج مضيء كعلامة معلم من أسوار المدينة، خارج نطاق المدينة (58م+).

## 4. قواعد التقدم (بلا مكافآت زائفة)

- الطابق 1 مفتوح دائمًا.
- بوابة الصعود في الطابق N مختومة حتى موت سيد الطابق N (حدث `creature_died` الحقيقي من قتال فعلي).
- المكافآت تأتي من مسار موت `Creature` القياسي فقط (XP/ذهب/غنائم) — لا منح تلقائي.
- هزيمة سيد الطابق 100 (أسترايوس، التاج الأبدي) تضع علم `tower_completed`.
- كل الأعلام داخل `WorldState.flags` (schema v3 موجود بالفعل) — بلا هجرة حفظ مطلوبة.
